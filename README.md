## 📌 Program Description

This project is an **Audio Player Application** developed as part of the
CS213: Object-Oriented Programming course at the Faculty of Computers and
Artificial Intelligence, Cairo University.

The application provides a graphical user interface for playing and
controlling audio files.

The project demonstrates the practical application of Object-Oriented
Programming concepts in C++, including:

- Classes and Objects
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Modular code organization
- Event-driven programming
- GUI development
- Audio playback and control

### 🛠️ Technologies Used

- **C++**
- **JUCE Framework**
- Object-Oriented Programming
- Git & GitHub
